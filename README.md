# Business Fast

Prototype web du jeu de plateau **Business Fast**.

## Version actuelle
**V0.39**

### Nouveautés V0.39
- Arrivée sur une case avec impact visuel et onde lumineuse.
- Transfert des loyers affiché directement sur le plateau.
- Gains Banque et flux d’argent davantage mis en scène.
- Cartes joueurs animées lors des gains, pertes et changements de tour.
- Événements avec entrée cinématique selon leur tonalité.
- Transition de tour plus visible.
- Toute la refonte graphique V0.38 est conservée comme base.

## Structure
- `index.html` — structure de l'interface
- `css/style.css` — direction artistique et responsive
- `js/game.js` — règles, gameplay, événements et mode développeur

## Lancer le jeu
Ouvrir `index.html` dans un navigateur moderne.
