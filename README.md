# Business Fast

Prototype web du jeu de plateau **Business Fast**.

## Version actuelle
**V0.38**

### Nouveautés V0.38
- Cases gauche/droite fortement élargies pour améliorer la lisibilité.
- Plateau global agrandi et moins carré.
- Centre légèrement resserré.
- Noms de villes et informations économiques plus confortables.
- Coins renforcés visuellement.
- Effets de profondeur et de survol améliorés.
- Cases spéciales avec assets SVG dédiés (Départ, Banque, Prison, Événement, Mondial).
- Centre enrichi : routes, pont, parc, skyline et zone Merveille plus visuelle.

## Structure
- `index.html` — structure de l'interface
- `css/style.css` — direction artistique et responsive
- `js/game.js` — règles, gameplay, événements et mode développeur

## Lancer le jeu
Ouvrir `index.html` dans un navigateur moderne.
